**EmptyState** — estado vacío con la marca de casa Noctis.

```jsx
<EmptyState
  title="Aún no hay productos"
  description="Cree el primero para empezar el catálogo."
  action={<Button variant="primary" style={{ height: 32 }}>Nuevo producto</Button>}
/>
```

Aparece solo donde no hay tenant (default sin color). El mark grafito + plata es identidad de plataforma; dentro del shell con tenant, no hay editorial.
